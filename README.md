# HTML5 Canvas Dino Game 🦖

A lightweight, pure JavaScript clone of the classic Chrome offline dinosaur game. This project runs directly in any modern web browser without requiring installations or server setups.

## Live Demo
🚀 **[Play the Game Live Here](https://github.io)**

---

## Features
* ⚡ **Zero Dependencies:** Built entirely with native HTML5, CSS3, and Vanilla JavaScript.
* 🌐 **GitHub Pages Ready:** Structured for instant deployment and hosting via GitHub.
* 🏃‍♂️ **Smooth Mechanics:** CSS-animated obstacle loops paired with precise JavaScript collision intervals.

---

## Gameplay Controls
* **[Spacebar]** or **[Up Arrow]**: Jump over obstacles

---

## How to Run Locally

You do not need to install anything to play or test this game locally:

1. **Download the code:** Clone or download this repository to your machine.
2. **Launch the game:** Double-click the `index.html` file to open it in any web browser (Chrome, Safari, Edge, Firefox).


## Deployment to GitHub Pages

To make this game playable online for free:
1. Go to your repository settings on GitHub.
2. Click on **Pages** in the left sidebar.
3. Under "Build and deployment", set the source Branch to **main** (or `master`) and click **Save**.
4. Your live link will generate at the top of that page within a few minutes!
